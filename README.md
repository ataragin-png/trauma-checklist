# צ'קליסט חדר טראומה

אתר בדיקות ציוד יומיות/שבועיות/חודשיות לחדר הטראומה, לאחיות ולבנות שירות, עם לוח מנהל לחוסרים ותקלות.

- האתר: GitHub Pages (הקבצים `index.html`, `config.js`).
- הנתונים: גיליון Google עם Apps Script (`apps-script/Code.gs`), שכתובתו מוגדרת ב-`config.js`.
- רשימת הציוד, כמויות התקן, הקודים ומייל ההתראות נערכים בגיליון עצמו.
